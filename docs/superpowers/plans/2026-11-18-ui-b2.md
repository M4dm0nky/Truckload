# UI-Bausteine Stufe B2 – Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Lucide-Symbole statt Zeichen und Phosphor, ein Popup-Kopf mit ×, eine per Token umschaltbare Segment-Leiste (Schnittstelle Version 3).

**Architecture:** Zuerst die pixelneutralen Teile (Token, Segment-Baustein, `symbol()`, `dialogKopf()`, CSS, Musterseite) mit vollem Bildvergleich = 0, dann der sichtbare Umzug der Ansichten. Symbole als SVG-Innenteile in `js/ui/symbols.js`, Ausgabe über `symbol()` in `js/ui/dom.js`. Popup-Kopf über `dialogKopf()`, × nimmt den vorhandenen Abbrechen-Weg.

**Tech Stack:** Vanilla CSS/ES-Module, `node --test`, headless Chrome über `tools/cdp.mjs`.

**Spec:** `docs/superpowers/specs/2026-11-18-ui-b2-design.md` (immer mitlesen; Vorgänger `2026-11-18-ui-bausteine-design.md`)

## Global Constraints

- Keine npm-Abhängigkeit, kein Build-Schritt, kein Netzzugriff zur Laufzeit. Jede neue Datei unter `js/`, `css/`, `vendor/` in `ASSETS` von `sw.js`.
- Neue Texte nur über `t()` mit Eintrag in `js/i18n/en.js`. „Schließen“ → „Close“; Schlüssel „⬛ Sonderbau“ wird „Sonderbau“ → „Scenic“.
- Lucide-Version `1.74.0` (wie NYX `frontend/src/lib/symbole.js`). Symbolnamen fest: `x`, `minus`, `plus`, `undo-2`, `redo-2`, `triangle-alert`, `circle-x`, `box`, `pencil-line`, `trash-2`. Innenteile 1:1; die NYX schon hat (`x`, `pencil-line`, `triangle-alert`, `undo-2`) dürfen aus NYX übernommen werden, die übrigen aus `https://unpkg.com/lucide-static@1.74.0/icons/<name>.svg` (geprüft erreichbar 2026-11-18). Nie Pfade abtippen.
- SVG-Ausgabe wie NYX: `<svg class="symbol" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true" focusable="false">…</svg>`; CSS `.symbol { width: 1.15em; height: 1.15em; flex: none; vertical-align: -0.2em }`.
- Token `--tl-segment-joined` (Standard `0`), `THEME_VERSION = 3`, `--tl-theme-version: 3`, Token hinten an `THEME_TOKENS`.
- ★ ◇ (in `<option>`), „+ “ vor Knopftexten, Malzeichen in Maßen, `+N`/`−N` als Text, `.lkw-tab`: unverändert.
- × im Popup-Kopf tut nur, was das Abbrechen des Popups tut; Fokus beim Öffnen nie auf dem ×.
- Kein Anfassen von `js/version.js`, `CHANGELOG.md`, `sw.js`-Cache-Name bis Task 7.
- Kein `git stash` (geteilt mit anderen Sitzungen). Gestartete `http.server`/Chrome am Ende beenden.
- Scratchpad: `SP=/private/tmp/claude-501/-Users-robs-Git-NYX/aeced5ff-872b-4f47-8606-9c22e6b23a20/scratchpad/tl-b2`.
